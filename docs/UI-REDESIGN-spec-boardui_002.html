远程桌面客户端：画面放在中间，其余界面都往后退

按 BoardUI 的设计语言重绘全部 12 个界面状态：浅灰托盘承载白色卡片、浮动圆角侧栏、渐变主按钮、按钮组工具栏，强调色可切换，明暗主题同构。

落地目标 leeconnect/src/bin/gui.rs（egui/eframe）· 更新 2026-11-23 · 取代 v1（深色 teal + IBM Plex）

强调色

01原则：分层靠明度，不靠描边

v1 用深色底和描边把每个区块框出来。v2 改用两级表面：浅灰托盘负责分区，白色卡片放内容，界面整体更轻，远端画面成为唯一的重色块。

  • 画面优先连接后远端画面占主体；侧栏、信息面板都可以收起，浮动工具条只保留 3 个高频操作。
  • 托盘承载卡片托盘 #F7F7F7（圆角 16、内边距 8）分区，白色卡片（圆角 10、1px 阴影）承载内容，不再每块都加描边。
  • 状态双编码实心点表示已连接，半环表示连接中，空心环表示未连接；延迟 <40ms 绿、40–90ms 黄、>90ms 红。
  • 一个强调色默认蓝 #2673FE，可换 6 种；危险操作只用独立的红色，并且必须二次确认。
  • 克制的按压反馈按下缩放到 0.97，悬停只换底色或描边，不用发光和阴影动画。
  • 明暗同构默认浅色，长时间会话推荐深色；两套 token 名称一一对应，组件代码只写一次。

中性色直接沿用 BoardUI 的 neutral 阶梯（与 Tailwind neutral 一致），状态色用 lime / yellow / rose 的浅底配深字。

13egui 落地：哪些能直接做，哪些需要近似

egui 没有 CSS 那样的渐变和多层阴影，下表列出每项在 gui.rs 里的做法。

规范egui 做法备注
托盘 / 卡片egui::Frame：fill = TRAY / CARD，圆角 16 / 10，inner_margin 8 / 12两级 Frame 嵌套即可
卡片阴影Frame 的 shadow：offset y=1，blur 2，黑色 5% 透明度Shadow 字段名随 egui 版本变化，按项目所用版本填写
渐变主按钮实色 ACCENT 填充，加 1px ACCENT_DEEP 描边需要真渐变时，用 Painter 画两色 Mesh
按钮组一个 Frame 包住 ui.horizontal，组内按钮去掉描边，激活态用 selectable_label激活色 = selection.bg_fill
状态胶囊自绘：painter.rect_filled 画底色，再画圆点或圆环半环用 Shape::line 画圆弧
按压缩放 0.97省略，改为按下时 fill 加深一级egui 没有逐控件的 transform
字体FontDefinitions 注册 Inter 和 Noto Sans SC，Noto 作为中文回退打包体积会增加，可只取常用字子集
// theme.rs · 浅色 token（深色同名，另建 mod dark）

pub const CARD: Color32        = Color32::from_rgb(0xFF, 0xFF, 0xFF);
pub const TEXT: Color32        = Color32::from_rgb(0x0A, 0x0A, 0x0A);
pub const TEXT_2: Color32      = Color32::from_rgb(0x73, 0x73, 0x73);
pub const ACCENT: Color32      = Color32::from_rgb(0x26, 0x73, 0xFE);

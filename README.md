# 服务器改动 · 漫画志（Server Manga Log）

黑白漫画风、手稿线条的**本地**改动记录软件：把你在服务器上做的每件事记成「一话」，其中的每一次改动就是「一格」漫画。

- 纯黑白灰：原稿纸 + 网点纸 + 速度线 + 毛笔手写字 + 手绘抖动边框
- 每格记录：时间 / 类型（配置・代码・部署・修复・排查・回滚）/ 结果（成功・待验证・失败）/ 一句话改动 + 细节
- 支持**贴图**（选图 / Ctrl+V 粘贴截图 / 拖拽，灯箱放大看）与**表格制作**（行列自由增减）
- 全部数据存在本地 `data.json`，只绑定 `127.0.0.1`，不上传任何东西
- 零依赖：不需要 `npm install`，只要有 Node.js

## 启动

**方式一（推荐）**：双击 `start.bat`，浏览器会自动打开。

**方式二**：命令行

```bash
node server.js
```

然后访问 http://127.0.0.1:4780 （若端口被占用会自动顺延，以启动时打印的地址为准）。

- 指定端口：`set PORT=8080 && node server.js`
- 不自动打开浏览器：`set NO_OPEN=1 && node server.js`
- 关闭：在窗口按 `Ctrl+C`（或直接关窗口）。

## 部署到服务器 · 外网访问

应用默认只监听 `127.0.0.1`（仅本机）。要放到服务器上给外网访问：

**第 1 步 · 传到服务器**（示例以 Linux + systemd 为准）：

```bash
scp -r I:/NEW/code/server-manga-log user@10.2.5.24:/opt/server-manga-log
ssh user@10.2.5.24 "apt install -y nodejs"   # 服务器上装 Node.js
```

**第 2 步 · 必须设口令**（不然外网谁都能改你的记录）：

```bash
cd /opt/server-manga-log
cp config.example.json config.json
vi config.json    # 把 accessCode 改成你自己的口令
```

**第 3 步 · 开机自启**：

```bash
sudo cp deploy/manga-log.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now manga-log
journalctl -u manga-log -f    # 看启动日志
```

此时内网可用 `http://10.2.5.24:4780` 访问，打开页面会先要求输口令。

**第 4 步 · 真正的外网访问**，按条件三选一：

| 方案 | 适用 | 做法 |
|---|---|---|
| **Cloudflare 快速隧道（无需任何资源，本项目已内置）** | 没有域名 / 公网 IP / VPS | 服务器上跑 `./start-tunnel.sh`，获得 `https://xxx.trycloudflare.com` 公网 HTTPS 地址，地址自动写入 `public_url.txt` |
| Cloudflare 命名隧道 | 有自己的域名 | 最稳：固定域名、永不换地址，`cloudflared tunnel create` 绑定后替换快速隧道 |
| frp / 路由器端口转发 | 有公网 VPS / 公网 IP | 常规方案，**务必配 HTTPS 反代**（nginx/caddy） |

**已部署实例的现状**（10.2.5.24）：

- 应用 + 隧道都已通过 crontab `@reboot` 开机自启（应用 15s、隧道 25s 错峰）
- 公网地址每次重启隧道会**变**，最新地址永远记录在服务器 `~/server-manga-log/public_url.txt`（`ssh 10.2.5.24 cat ~/server-manga-log/public_url.txt`）
- 口令锁必须保持开启——公网地址任何人都能撞到，全靠口令挡人

安全说明：

- **内网直连（10.x / 192.168.x / 172.16-31.x / 127.0.0.1 等）免口令**，直接打开就用；公网来源（如隧道访客）才要求登录
- 判定以 Cloudflare 注入的真实访客 IP 为准（CF-Connecting-IP），伪造该头假装公网会被 fail-closed 拦下要求口令，无法借道绕过
- 公网访客错误口令 5 分钟内限试 20 次；Cookie 为 HttpOnly + SameSite=Lax，有效期 30 天；页脚「⎋ 退场」可退出登录；**改口令 = 所有会话立即失效**
- 口令锁是共享密钥（全站一个口令），适合个人/小组使用；如果要求多用户各账号，需要再升级
- 不设 `ACCESS_CODE` 时口令锁完全不启用（连公网也不拦，此时不要暴露公网）
- 服务器部署时端口必须钉死（隧道指向 4780）：端口被占会直接报错退出，`PORT_AUTOINCREMENT=1` 才会顺延（本地 start.bat 已默认开）

## 功能速览

| 功能 | 说明 |
|---|---|
| 开新话 | 左栏「＋ 开新话」：一件服务器上的事 = 一话（标题 / 主机 / 状态 / 标签 / 备注） |
| 记一格 | 右栏虚线格表单：一次改动 = 一格（时间 / 类型 / 结果 / 标题 / 细节） |
| 快记一笔 | 顶部⚡快记条：一句话回车入格，**类型按关键词自动识别**（如 systemctl→部署，回滚→回滚） |
| 贴图 | 格表单「📎 贴图」选文件，或直接 **Ctrl+V 粘贴截图** / 把图拖进细节框；一格最多 9 张；点缩略图灯箱放大 |
| 文档 | 格表单「📄 文档」挂附件：日志 / 配置 / 脚本 / PDF / Office / 压缩包等（单件 50MB，一格最多 10 个），点文件卡片**在线预览**——CSV/TSV 转表格、文本/YAML/代码黑底码块、PDF 内嵌查看，其余提示下载 |
| 正文排版 | 细节与备注两端对齐；路径 / 文件名 / 命令 / 链接自动区分呈现（渲染时识别，不改原文） |
| 表格 | 格表单「⊞ 表格」插入可编辑表格：行列自由增减（≤12 列 × 100 行），适合压测数据 / 对比结果 |
| 遗留事项 | 每话的待办清单，勾掉自动划线；数据条实时显示「遗留 N 件」 |
| 目次 / 统计 | 左栏页签切换；**卷末统计**：近十二周节奏图、类型 / 主机分布、战果大数字、最勤快的话 TOP3 |
| 筛选 | 按状态（进行中 / 已完成 / 搁置）过滤目次，配合搜索（标题 / 主机 / 标签 / 改动内容） |
| 编辑 / 撕掉 | 每格「✎ 改 / ✕ 撕」；每话「✎ 编辑本话 / ✕ 整话撕掉」（二次确认；撕掉的格自动清理其图片文件） |
| 导出 | 「⇩ 导出全稿」全部记录 → Markdown；「⇩ 本话」只导当前话（图片 / 表格一并写入） |
| 备份 | 卷末统计页「⇩ 导出备份」下载 data.json；「⇒ 导入备份」覆盖恢复（可当跨机搬家） |
| 快捷键 | `N` 开新话，`/` 聚焦搜索，`Ctrl+Enter` 提交弹窗 / 表单，`Esc` 关闭弹窗灯箱 |
| 口令锁 | 设 `ACCESS_CODE`（环境变量或 config.json）后全站需登录，配 30 天免登录会话；外网部署必开 |
| 自动同步 | 页面每 10 秒检测外部写入（如脚本录入），自动重绘且不打断正在编辑的草稿 |

## 数据与备份

- 记录保存在 `./data.json`；上传的图片与文档都存在 `./uploads/`（自动建目录）。
- 支持的文档类型：文本类（txt/log/md/csv/json/yaml/conf…）、Office 与 PDF（doc/docx/xls/xlsx/ppt/pptx/pdf…）、代码（py/sh/sql/js/ipynb…）、压缩包（zip/tar/gz/7z/rar）、证书（pem/key/csr/cnf）。非图片附件一律作为下载，不在页面内执行。
- **JSON 备份不含图片与文档文件**：跨机搬家时把 `data.json` 和整个 `uploads/` 目录一起拷走。
- data.json 损坏时会自动备份为 `data.json.bak-时间戳` 并重建示例。
- 首次启动内置 3 话示例（Nginx 证书、磁盘告警、灰度发布），不需要就整话撕掉。

## 目录结构

```
server-manga-log/
├── server.js            # 本地服务 + API + 图片/文档上传（零依赖）
├── start.bat            # Windows 双击启动
├── data.json            # 你的全部记录（首次启动自动生成）
├── uploads/             # 贴图与文档存放目录（自动创建）
└── public/
    ├── index.html       # 页面骨架
    ├── style.css        # 黑白漫画 / 手稿线条样式
    ├── app.js           # 前端逻辑（无框架）
    └── assets/fonts/    # 内置手写字体（马善政毛笔体 + 霞鹜文楷 Lite）
```
